# Практика 2.2 API входа

Я реализовал GET /api/login?login=… . SQL использует параметр `?`; ответ содержит id, full_name и role. Для неизвестного логина возвращаю 404, для пустого 400. Пароль не требуется по условиям работы. После входа сервер выдаёт случайную сессию в HttpOnly cookie и проверяет роль в запросах заказов.

Проверил admin, manager, client1, client2, client3 — пять демонстрационных пользователей. Также проверил отсутствующий логин и строку с SQL-инъекцией. [Фактические ответы curl](evidence/curl.txt), [автотесты](evidence/tests.txt), [браузерная проверка](evidence/browser.txt). Это не логины из отсутствующего Users_import.xlsx.

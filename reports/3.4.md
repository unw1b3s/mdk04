# Практика 3.4 Поиск информации в документации

Я изучил шесть разделов официальной документации и применил их в проекте. Дата обращения: 27.10.2026. [Конспект в PDF на одну страницу](3.4.pdf).

**http.server (Python 3.8).** BaseHTTPRequestHandler обрабатывает HTTP-запросы через методы do_GET и do_POST. Статус и заголовки нужно отправить перед телом, в wfile записываются байты. Применил в Handler и send_data в server.py.
[Документация](https://docs.python.org/3.8/library/http.server.html).

**sqlite3 (Python 3.8).** Подключение создаётся через connect; executescript выполняет SQL-скрипт. Значения передаются параметрами `?`, а не подстановкой строк. Контекст подключения фиксирует транзакцию или откатывает её при исключении; само подключение нужно закрыть отдельно. Применил в create_db.py, запросе входа и транзакции изменения заказа в server.py.
[Документация](https://docs.python.org/3.8/library/sqlite3.html).

**zipfile (Python 3.8).** ZipFile открывает ZIP-архив, read получает байты указанного файла внутри архива, with закрывает архив. Применил в tools/read_material.py: DOCX является ZIP, из word/document.xml читается текст индивидуального листа без Word и внешних библиотек.
[Документация](https://docs.python.org/3.8/library/zipfile.html).

**fetch (MDN).** Возвращает Promise с Response. HTTP-ошибка 404 сама не отклоняет Promise: нужно проверить response.ok. Метод response.json асинхронно читает JSON. Применил в функции api в static/app.js.
[Документация](https://developer.mozilla.org/en-US/docs/Web/API/Window/fetch).

**addEventListener (MDN).** Регистрирует обработчик события. На submit вызываю preventDefault, чтобы форма не перезагружала страницу. Применил для входа, сохранения заказа и кнопок.
[Документация](https://developer.mozilla.org/en-US/docs/Web/API/EventTarget/addEventListener).

**JSON.stringify (MDN).** Преобразует JavaScript-объект в JSON-строку. Применил в api перед POST; Content-Type указываю application/json. Сервер разбирает строку через json.loads.
[Документация](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/JSON/stringify).

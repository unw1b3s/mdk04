# Практика 2.1 HTTP сервер

Я создал сервер на BaseHTTPRequestHandler и ThreadingHTTPServer. Метод do_GET отдаёт разрешённые статические файлы и JSON API, do_POST обрабатывает сохранение заказа и выход. MIME-типы определяю через mimetypes. Статика ограничена явным списком файлов, база и исходный код через HTTP не доступны.

Проверил curl и браузером. [Вывод curl](evidence/curl.txt), [тесты](evidence/tests.txt). POST API реально проверен при изменении заказа. По умолчанию сервер работает на localhost:8000; фактический запуск для проверки был на 8001 из-за занятого 8000.

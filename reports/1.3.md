# Практика 1.3 Создание БД из Python

Я написал `create_db.py`: он подключается через sqlite3, выполняет schema.sql методом executescript, получает таблицы из sqlite_master и пишет результат в лог. Ошибки SQLite и чтения файла выводятся с завершением с кодом 1.

Запустил `python3 create_db.py` и отдельно `python3 demo_data.py`. Получил `shop.db`, восемь таблиц. [Лог создания](evidence/create_db.txt), [результат заполнения](evidence/demo_data.txt). Повторное создание схемы не удаляет данные. Демонстрационное заполнение вынесено отдельно и не подменяет импорт преподавателя.

Фактический запуск был на macOS с Python 3.14. ROSA Linux недоступна, проверку на ней не выполнял.

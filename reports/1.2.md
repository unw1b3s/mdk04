# Практика 1.2 Создание схемы БД

Я написал `schema.sql` для справочников, товаров, остатков, пользователей, заказов и позиций. Восемь таблиц связаны внешними ключами; размер и количество относятся к складской позиции, цена продажи сохраняется в позиции заказа.

Использовал PRIMARY KEY, FOREIGN KEY, UNIQUE, CHECK и ON DELETE CASCADE. Каскад удаляет позиции при удалении заказа. Включил `PRAGMA foreign_keys = ON`, добавил индексы для категорий, производителей, дат, клиентов и товаров в заказах.

Выполнил скрипт через sqlite3 на отдельной пустой базе. [Команда и вывод](evidence/schema_check.txt), [вывод .tables для shop.db](evidence/tables.txt). Ограничения и каскад проверил автоматическими тестами. Исходные данные преподавателя отсутствуют; схема используется для моего учебного примера.

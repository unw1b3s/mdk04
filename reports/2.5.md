# Практика 2.5 Каркас SPA

Я создал index.html, app.js и style.css. В state хранятся user, products, cart и filters. Функция api использует fetch, проверяет статус ответа и читает JSON. Шапка показывает вход, ФИО после входа, выход и кнопку пустой корзины. Страницы меняются без перезагрузки.

Для проверки связи с БД добавил простой список товаров. Содержимое корзины и фильтрация не реализованы: в этой работе нужен каркас. Панель заказов использует тот же state и api.

Проверил в настоящем Chrome. [Скриншот страницы](evidence/01_catalog.png), [мобильный вид](evidence/05_mobile.png), [протокол](evidence/browser.txt). В проверенном сценарии ошибок Console и pageerror нет.
